# 품질부서 인력 현황 포털

## 그냥 열어보기 (내 컴퓨터에서만)

`index.html`을 더블클릭하면 바로 열립니다. 설치나 서버 실행이 필요 없습니다.

## 사내 다른 컴퓨터에서도 함께 보려면

공유 폴더에 넣고 다른 컴퓨터에서 `index.html`을 직접 열면(특히 `file://` 경로로), 브라우저 보안 정책 때문에 흰 화면만 뜨고 아무것도 로드되지 않을 수 있습니다. 이 문제를 피하려면 이 폴더가 있는 컴퓨터에서 간단한 서버를 켜두고, 다른 컴퓨터에서는 `http://` 주소로 접속하면 됩니다.

1. 이 폴더가 있는 컴퓨터(서버 역할)에 [Node.js](https://nodejs.org)가 설치되어 있어야 합니다 (이미 `npm run build`를 해봤다면 이미 설치되어 있는 것입니다).
2. `start-server.bat` 파일을 더블클릭합니다 (또는 터미널에서 `npm run serve` 실행).
3. 실행하면 터미널 창에 접속 주소가 뜹니다. 예:
   ```
   이 컴퓨터에서 접속: http://localhost:8080

   사내 다른 컴퓨터에서 접속 (같은 네트워크에서만 가능):
     http://192.168.100.10:8080
   ```
4. 사내 다른 컴퓨터에서는 브라우저(크롬 권장)에 위 `http://192.168.100.10:8080` 같은 주소를 그대로 입력해서 접속합니다.
5. 이 서버를 띄운 창을 닫으면 다른 컴퓨터에서 더 이상 접속할 수 없습니다 — 계속 켜두어야 합니다. 컴퓨터를 켤 때마다 자동으로 실행되게 하려면 `start-server.bat`의 바로가기를 시작프로그램 폴더에 넣어두면 됩니다.

⚠️ 데이터는 각 컴퓨터의 브라우저(localStorage)에 저장되어, **컴퓨터마다 따로 저장됩니다.** 즉 A 컴퓨터에서 입력한 내용이 B 컴퓨터 화면에 자동으로 나타나지는 않습니다. 같은 데이터를 여러 컴퓨터에서 보려면 아래 "데이터 내보내기/불러오기"를 사용하세요.

## 데이터를 여러 컴퓨터에서 함께 보려면 (서버 없이)

서버를 켜지 않고도, 전체 명단 화면의 **내보내기/불러오기** 버튼으로 데이터 파일을 주고받을 수 있습니다.

1. 데이터를 입력한 컴퓨터에서 전체 명단 탭 → **내보내기** 클릭 → `quality-portal-data-날짜.json` 파일이 다운로드됩니다.
2. 이 파일을 사내 공유 폴더(예: `QC HR Management` 폴더)에 옮겨둡니다.
3. 다른 컴퓨터에서 `index.html`을 열고 전체 명단 탭 → **불러오기** 클릭 → 공유 폴더의 그 파일을 선택합니다.
4. 확인 창이 뜨면 계속 진행 — 그 컴퓨터의 기존 데이터가 파일 내용으로 전부 바뀝니다.

⚠️ 자동 동기화가 아니라 **수동으로 파일을 주고받는 방식**입니다. 데이터를 수정할 때마다 내보내기 → 공유 폴더에 덮어쓰기 → 다른 컴퓨터에서 불러오기를 반복해야 최신 상태로 유지됩니다. 두 컴퓨터에서 동시에 다른 내용을 수정하면 나중에 불러온 쪽이 앞선 수정 내용을 덮어쓰니, 한 번에 한 사람만 수정하는 것을 권장합니다.

## 코드를 수정하려면

1. `src/QualityPortal.jsx`를 수정합니다.
2. 아래 명령으로 다시 빌드합니다 (최초 1회는 `npm install` 필요).

   ```bash
   npm install
   npm run build
   ```

3. `index.html`을 다시 열면 변경 사항이 반영됩니다.

수정하면서 바로바로 확인하고 싶다면 `npm run watch`로 저장할 때마다 자동으로 다시 빌드되게 할 수 있습니다 (브라우저 새로고침은 직접 해야 합니다).
