# 품질부서 인력 현황 포털

## 그냥 열어보기 (내 컴퓨터에서만)

`index.html`을 더블클릭하면 바로 열립니다. 설치나 서버 실행이 필요 없습니다.

## 사내 다른 컴퓨터에서도 함께 보고, 데이터도 자동으로 동기화하려면

공유 폴더에 넣고 다른 컴퓨터에서 `index.html`을 직접 열면(특히 `file://` 경로로), 브라우저 보안 정책 때문에 흰 화면만 뜨고 아무것도 로드되지 않을 수 있습니다. 또 `file://`로 열면 각 컴퓨터의 브라우저에 데이터가 따로 저장되어 서로 공유되지 않습니다. 이 폴더가 있는 컴퓨터에서 서버를 켜두고 다른 컴퓨터들이 `http://` 주소로 접속하면 두 문제가 한 번에 해결되고, **데이터도 5초마다 자동으로 동기화**됩니다.

1. 이 폴더가 있는 컴퓨터(서버 역할)에 [Node.js](https://nodejs.org)가 설치되어 있어야 합니다 (이미 `npm run build`를 해봤다면 이미 설치되어 있는 것입니다).
2. `start-server.bat` 파일을 더블클릭합니다 (또는 터미널에서 `npm run serve` 실행).
3. 실행하면 터미널 창에 접속 주소가 뜹니다. 예:
   ```
   이 컴퓨터에서 접속: http://localhost:8080

   사내 다른 컴퓨터에서 접속 (같은 네트워크에서만 가능):
     http://192.168.100.10:8080
   ```
4. 사내 다른 컴퓨터에서는 브라우저(크롬 권장)에 위 `http://192.168.100.10:8080` 같은 주소를 그대로 입력해서 접속합니다. (이 컴퓨터 자신도 `http://localhost:8080`으로 열어야 동기화가 됩니다 — `index.html`을 더블클릭해서 열면 동기화되지 않습니다.)
5. 이 서버를 띄운 창을 닫으면 다른 컴퓨터에서 더 이상 접속·동기화가 안 됩니다 — 계속 켜두어야 합니다. 컴퓨터를 켤 때마다 자동으로 실행되게 하려면 `start-server.bat`의 바로가기를 시작프로그램 폴더에 넣어두면 됩니다.

데이터는 이 서버 컴퓨터의 `data.json` 파일에 저장됩니다. 이 파일을 지우면 데이터가 초기화되니 주의하세요. 접속한 각 컴퓨터는 5초마다 이 파일의 최신 내용을 자동으로 확인해서 화면에 반영하고, 누군가 수정하면 잠시 뒤(1초 이내) 서버에 자동 저장됩니다. 여러 사람이 동시에 서로 다른 내용을 수정하면 **나중에 저장되는 쪽이 앞선 수정 내용을 덮어쓸 수 있으니**, 가능하면 한 번에 한 사람만 수정하는 것을 권장합니다.

## 코드를 수정하려면

1. `src/QualityPortal.jsx`를 수정합니다.
2. 아래 명령으로 다시 빌드합니다 (최초 1회는 `npm install` 필요).

   ```bash
   npm install
   npm run build
   ```

3. `index.html`을 다시 열면 변경 사항이 반영됩니다.

수정하면서 바로바로 확인하고 싶다면 `npm run watch`로 저장할 때마다 자동으로 다시 빌드되게 할 수 있습니다 (브라우저 새로고침은 직접 해야 합니다).
